# Artifacts

Evidence for Jira worklogs, one folder per sprint.

The team grading rubric requires every non-reporting work unit to have at least
one worklog containing a GitHub commit/PR link **or** a link into `/artifacts`
or `/docs`. This directory is where the non-code evidence goes: screenshots,
demo recordings, exported diagrams, deployed URLs.

Naming: `artifacts/sprint-NN/short-description.png`

Link format to paste into a Jira worklog:

    https://github.com/<org-or-user>/imgtranslate/blob/main/artifacts/sprint-01/signup-flow.png
