# Artifacts

Evidence for Jira worklogs — screenshots, recordings, exported diagrams, deployed URLs that don't belong in a commit.

Currently empty. Nothing is backfilled here from before this convention existed — files get added as each sprint actually produces something worth a worklog link.

## Naming

No per-sprint subfolders. Prefix the filename with the sprint number instead:

artifacts/sprint06-camera-capture.png
artifacts/sprint07-tts-demo.mp4


## Link format to paste into a Jira worklog

https://github.com/<org-or-user>/imgtranslate/blob/main/artifacts/sprint06-camera-capture.png


## Policy

Drop the file in the same day the work happens — not retroactively at sprint end.
